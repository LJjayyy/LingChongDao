# 产品首页展示素材

- `intro.mp4`：原有《灵宠岛 · 30 秒宣传片》的完整成片，1920 × 1080、30 秒、H.264 / AAC，使用示例任务；从本地交付文件复制，未重新剪辑或更换音乐。
- `intro-cover.png`：同一宣传片的原有封面，沿用老板鼠、暖纸色与铜色的产品视觉。
- `overview.png`、`attention.png`、`boss-idle.png`、`connections.png`：从当前 SwiftUI 产品视图渲染的示例界面，分别展示收起/展开、待回答、老板鼠查岗和接入应用。任务是合成数据；来源配置与宠物读取指向隔离目录，不读取真实会话或宠物数据库。应用标识从安装包资源读取，绕过 Finder 自定义图标。
- `attention-flow.svg`：原创静态示意图，说明“抬眼看 → 展开看 → 回现场”，采用 MIT 许可。
- `pet-family.png`：作者提供的个人桌面截图，经内置 imagegen 精修为灵宠合影，清理聊天窗口与 Dock 背景，统一留白与暖纸色背景。瓶盖猫、白底小黄鸭和老板鼠下方分别标注 ChatGPT、Qoder CN、灵宠岛，用于 README 的命名故事；编辑提示词见 [制作记录](source/pet-family-edit.md)。

界面图的可复现入口为 `source/render-showcase.sh`，需要与源码构建相同的 macOS 工具链和图形会话。它构建演示程序并在屏幕外渲染，不安装应用、接入来源工具或修改用户配置；电源状态使用不会调用系统服务的示例后端。任务画面和素材范围见 [素材说明](../../THIRD_PARTY_NOTICES.md)。

README 使用从本仓库 README 编辑器上传的 GitHub 视频附件，在页面内显示原生播放器。附件地址为 `https://github.com/user-attachments/assets/04e7e4d5-7650-44f9-9cf1-bf679a2e9e2e`，原始成片和封面仍保留在此目录。仓库文件页不提供这个 MP4 的播放器，因此不再把该文件页当作观看入口。

上传时仓库为私有；已验证登录后可播放、未登录请求返回 404。公开仓库前应重新检查播放器的访问状态；不把重定向产生的临时签名地址写入 README。

视频配乐来源记录为 Francisco Alvear 的《Upbeat Jazz》，Mixkit 曲目 644；音效来源记录为 Kenney、unicaegames 及制作模板的合成音效。素材与第三方角色、品牌的原有权利分别适用，成片及封面不纳入代码 MIT 授权，详见 [素材说明](../../THIRD_PARTY_NOTICES.md) 与 [配乐记录](../../docs/宣传配乐与分发.md)。

公开展示文件为产品介绍成片、封面、示例界面、灵宠合影及设计示意图；宣传源工程、字体文件、独立配乐/音效原文件、其他来源宠物的逐帧素材仍留在本地忽略目录 `promo/`。
