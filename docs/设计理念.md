# 这座小岛是怎么想的

[返回产品首页](../README.md)

AI 忙起来，可以同时替你写代码、查资料、改方案。你却常常还得逐个窗口确认：它做完了吗？卡住了吗？是不是在等我？

灵宠岛想帮你接住这些小事，让你放心去忙自己的事。设计的起点，是把注意力还给你。

## 1. 平时在旁边，有事再喊你

像办公室里一位懂分寸的同事：工作在进行时，你抬眼就能知道；需要你回答或确认时，再把事情递到面前。

这借鉴了「平静技术」的想法：信息可以先待在注意力的边缘，需要时再走到中心。灵宠岛平时收成顶部的一小块，重要状态到来时展开提醒。

参考：[Calm Technology 的设计原则](https://calmtech.com/)。

## 2. 先给重点，想了解时再展开

收起时看状态，展开后看任务，需要完整内容再回原来的工具。你不用为了确认一句“做完了”，先读一整页内容。

设计里常把这叫「渐进呈现」：先展示当前最需要的信息，把进一步的细节留给想看的人。岛、展开卡片、原来的对话，各自负责一层。

参考：[Nielsen Norman Group：Progressive Disclosure](https://www.nngroup.com/articles/progressive-disclosure/)。

## 3. 让你知道发生了什么

「还在做」「等你点头」「本轮结束」是不同的事情。我们用明确的状态、文字和适当的颜色，把它们分开说清楚。

这对应「系统状态可见」的原则。没有可信的总步骤数时，不编造一个进度百分比；来源只报告本轮停止时，也不替它宣布任务成功。重要决定仍由你确认。

参考：[Nielsen Norman Group：Visibility of System Status](https://www.nngroup.com/articles/visibility-system-status/)。

## 4. 让等待多一点人味

老板鼠有点严肃，也有点欠揍。它眨眼、抬头、指点两句，把抽象的等待变成一个有表情的小场景。

这是我们对陪伴感的选择：角色负责表达，任务状态负责讲事实。点击和悬停有回应；开启系统“减少动态效果”后，会收敛动作，保留必要信息。

暖纸色的工作台和黑色的小岛也各有分工：工作台适合坐下来整理，小岛适合工作时抬眼看一眼。你继续在熟悉的 AI 工具里工作，灵宠岛负责在旁边接住提醒。
