# 灵宠岛展开动效

方向：像贴着刘海长出的同一个柔性实体，反馈迅速、展开有分量、收回利落。保持黑色外壳、彩色数量和真实来源宠物，不新增玻璃材质、光晕或装饰性循环。

Apple依据：
- [Motion HIG](https://developer.apple.com/design/human-interface-guidelines/motion)：反馈简短、精准、可取消，触控板反馈克制。
- [Animate with springs](https://developer.apple.com/videos/play/wwdc2023/10158/)：位置与速度连续，打断后从当前状态重定向；弹簧不等于夸张反弹。
- [Animatable data](https://developer.apple.com/documentation/swiftui/animatable/animatabledata-6nydg)：形状参数逐帧插值。

这些是 Apple 通用指南，未把调校参数声称为 macOS 27 官方固定参数。

实现：
- 悬停识别140ms；提示只微增12×3pt，宠物最多放大8%。离开180ms后收起，可快速移出/移回打断。
- 外壳统一弹簧：悬停预反馈、展开与收起均使用0.42秒感知时长、bounce 0.045、blendDuration 0.08，延续当前速度。肩部和底角用同一个连续进度插值。
- 展开内容常驻、在最终宽度预先测量；关闭时隐藏并禁用点击、键盘与无障碍访问，避免先撑到估计高度再闪缩。
- 内容晚35ms开始淡入，淡入200ms、退出100ms；文字不拉伸、不使用动态模糊。首只宠物共享位置与尺寸，编辑锁定时保持稳定布局。
- 原生窗口高度固定保留504pt（480pt最大外壳加24pt阴影），收起后不回收高度；宽度高水位仍保留620ms，避免快速重入时裁剪。
- 系统减少动态效果开启时，直接到目标几何、取消共享空间运动、取消宠物悬停缩放。

验证：`verify-compact-window.sh` 的34项几何与异步悬停检查连续运行三轮通过，覆盖快速进出取消、退出后重入、显式打开不被延迟hover任务覆盖、编辑与busy保护、idle不展开及几何边界；release构建与签名校验通过。

原生界面已检查运行列表和问答卡片的展开布局、文字与外壳裁切，以及输入后Escape收回、重新展开保留草稿。预览已结束。当前自动化工具不提供单独移动鼠标的接口，未取得完整的悬停逐帧录像，也未测量刷新率；连续快速悬停的状态转换由上述异步检查覆盖。系统减少动态效果分支经过代码复审，未更改用户系统设置进行实机切换。


## 0.1.6 首次悬停修复

触发：收起并静置后，首次移入会显得生硬；连续移入移出则顺滑。0.1.5在悬停预反馈时用0.30秒弹簧，正式展开时切换为0.42秒。尺寸已在运动，肩部与圆角的形变随后才开始；实际视图的路径观测显示两者节奏分离。

复现使用真实`IslandView`、`IslandWindowCoordinator`、`IslandPanel`和`IslandShell.path`，固定测试指针位置并隔离会话。仅向临时外壳源码副本加入被动路径观测，不替换实际frame或动画链。旧版冷展开三轮中段尺寸与形变的归一化进度最大差约0.14–0.18，热重开约0.001。该数据是形状求值记录，不是显示帧率。

单变量对照：保持画布回收和悬停逻辑，仅把外壳弹簧时长统一为0.42秒，冷展开与热重开均通过同步检查。进一步移除blendDuration未显示决定性改善，因此保留0.08。生产修复采用统一弹簧时长，收回外壳也使用该弹簧，内容仍在100ms内淡出。

`scripts/verify-motion.sh`覆盖静置后的首次悬停、连续重开、短暂离开重入以及预览内容刷新，检查实际形状的尺寸与圆角进度，并验证中间值和最终状态。它不发送全局输入，不连接来源Hook，不读取真实宠物配置，不估计FPS。

0.1.6验证结果：正式动效检查8/8通过，冷展开最大同步误差约0.016–0.036，热重开约0.003；34项几何与悬停状态检查通过。Release构建、签名校验、本地桥接ping通过。实机检查运行列表、问答输入锁定和Escape收回，预览已结束，正常任务活动继续显示。系统减少动态效果分支此次只做静态复审，未切换用户设置。

正式回归的负对照也已执行：仅在临时视图副本恢复旧的0.30/0.42秒分支，同一测试变为3/8通过，三次冷展开均失败（同步误差约0.16–0.18），热重开仍通过。生产源码不作回退。该对照确认新增断言能检出本次问题。


## 0.1.7 呈现层顶边下跳修复

用户提供的录屏显示：首次展开时整个黑壳顶边向下移动31px与46px，再弹回屏幕顶部；连续重开没有该位移。0.1.6虽然通过了路径形变同步检查，仍遗漏了宿主坐标布局进入动画的情况，因此旧检查不能视为完整视觉流畅度证明。

独立原生测试读取测试进程自有`NSHostingView`表面图层的`CALayer.presentation()`，观察到冷展开的root-relative顶边从0跳到73.46pt，再回到0；热重开始终0。形状路径检查此时仍通过。只把画布高度固定为504pt后，两条路径的呈现顶边都保持0，其余参数、宠物、内容和悬停逻辑均未改变。

正式修复只固定纵向宿主空间，并保留原宽度高水位和620ms释放策略。命中区继续只跟随可见外壳，透明部分不属于交互区域。实机已点击验证收起态透明画布下方的工作台控件可操作。

`scripts/verify-motion.sh`加入独立的呈现层顶边断言，观察绝对root-relative位置而非每段首样本基线；无法可靠识别表面图层时失败。采样间隔不是显示帧率。真实外接屏热插拔与系统减少动态效果切换本轮未实测。

0.1.7最终验证：形变同步8/8通过，呈现顶边8/8通过，所有段峰值0.00pt、图层映射错误为0，且验证了进入后的早段采样覆盖。使用同一正式测试，仅在临时协调器副本恢复旧动态画布高度，形变仍8/8通过，但呈现顶边仅热重开3/8通过，冷展开峰值约73–74pt，映射错误仍为0。34项几何/悬停状态检查通过，release签名和本地桥接通过。本机工作台确认运行0.1.7构建8，测试预览已结束。
