灵宠岛 · 安装与连接

系统要求：macOS 14 或更新版本，Apple Silicon（M 系列）Mac。

1. 将“灵宠岛.app”拖到旁边的“Applications”（应用程序）。
2. 从“应用程序”打开“灵宠岛”，即可看到老板鼠工作台和屏幕顶部的岛。
3. 打开“连接的应用”，为自己使用的 Codex、Qoder CN、Claude Code 等应用安装插件或连接配置。
4. 按来源要求审查并启用插件，重启来源应用，再开启新会话验证活动。

灵宠岛已包含老板鼠动画、应用图标和接入 helper。
普通使用无需安装 Swift、Python、Node，也无需在灵宠岛填写模型 API Key。
实际 AI 会话继续由你已经安装的来源应用提供。

首次打开

本版与 ClearZip 一样采用 ad hoc 签名，尚未使用 Developer ID 证书或 Apple 公证。
首次打开若被 macOS 拦截，请确认安装包来源后，按 Apple 官方说明处理：
https://support.apple.com/zh-cn/102445

日常使用与更新

关闭工作台后，菜单栏和顶部岛继续运行；从菜单栏可重新打开工作台或退出。
当前需手动启动和更新。更新前先从菜单栏退出，再将新版拖入“应用程序”替换旧版。
卸载前可先在“连接的应用”中卸载或断开对应来源的插件。
