# 卸载与数据清理

日常更新只需退出旧版，再将新版从 DMG 拖入“应用程序”替换。以下步骤用于完整卸载；如需保留设置供重装，可保留本地数据和偏好。

1. 在灵宠岛“连接的应用”中，对已经接入的来源逐个卸载插件或断开连接。插件由来源管理器登记，不能仅靠删除 App 或插件目录完成卸载。仅移除本项目的接入，不删除整个来源配置。
2. 按来源要求重启或开启新会话，确认不再加载旧 Hook。若准备回滚来源配置，先对照 `*.lingchongdao-backup-*` 备份，仅还原需要的部分，避免覆盖后来新增的其他设置。
3. 关闭“保持唤醒”，等待恢复完成。如提示“重试恢复休眠”，先完成该操作和管理员授权。随后从菜单栏退出灵宠岛。
4. 将 `/Applications/灵宠岛.app` 移到废纸篓。可将 `~/Library/Application Support/LingChongDao/` 一并移到废纸篓；其中含 helper、归属清单、本地插件副本和桥接目录。
5. 如需清除设置和草稿，退出应用后在终端执行 `defaults delete local.lingchongdao.app`。此操作清除本项目全部偏好，执行前保存需要的草稿。没有该偏好域时，macOS 会报告不存在，无需重复执行。
6. 按需移走各来源配置目录内的 `*.lingchongdao-backup-*` 文件。这些备份不会自动过期，可能包含敏感配置；不要删除其他工具的备份或整个配置目录。

旧版用户可能还有 `~/Library/Application Support/AIIsland` 兼容链接及 `local.ai-island.app` 偏好域。确认所有旧会话和旧接入都已停用后，可移除该兼容链接，并按需执行 `defaults delete local.ai-island.app`；否则下次迁移可能再次带回旧设置。通过访达确认兼容链接本身，避免误操作其指向的数据目录。

使用 `CODEX_HOME` 或来源配置目录覆盖项时，插件登记和备份可能位于自定义目录，以连接详情和来源插件管理器为准。不要删除 `.codex`、`.claude`、`.qoder-cn` 等整个来源目录。

权限请求在桥接退出或超时时交回来源流程，不会因删除 App 自动批准。具体数据与保留范围见 [隐私说明](../PRIVACY.md)。
