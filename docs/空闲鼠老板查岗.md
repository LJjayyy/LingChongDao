# 空闲鼠老板查岗

0.1.28 的新增彩蛋。设计方向：屏幕顶部是老板鼠巡视工位的舞台，空闲时发现全员摸鱼，主动任务到来时交给任务信息。

## 表现

沿用黑色岛壳、现有弹簧、白色台词和橙色小标题，复用既有 16 帧老板鼠素材，不更换角色画风。空闲收起态仍只保留老板鼠；稳定悬停 280ms 后展开约 420pt 宽的查岗小舞台。先巡视，再播放瞪眼、竖指、碎碎念和收手的一次表演，约 340ms 后让吐槽淡入。台词区域固定两行高度，换句话不会把面板顶高。

初次台词“好家伙，全员带薪摸鱼？”，后续轮换“工资在跑，进度条怎么没动？”“人呢？我的牛马怎么都下线了？”等八句。戳老板鼠会换句吐槽并表演一次，已有动作队列最多接一轮续播。右侧工作台入口保持真实可用，下方继续提供咖啡杯开关。

## 交互边界

- 快速划过不展开；移出 180ms 后自动收起，短暂返回会取消收起且不重播。
- 稳定悬停只演一次，移出并重新进入才轮换台词。
- 空闲悬停不取得键盘焦点；Escape、显式收起和屏幕销毁会取消等待。
- 新任务到来时让已有展开面板显示任务，沿用原有任务 hover 时长 140ms。
- 手动展开的最后任务结束时，释放其展开状态，再按空闲延迟进入查岗，避免空白卡片。
- 隐藏的查岗头像不挂载动画；系统“减少动态效果”开启时直接显示静态表情和台词。
- 查岗只改变角色表现，不创建任务或执行命令。

## 验证

异步悬停检查初版 60 项连续三轮通过。独立只读复审发现并修复了手动展开任务结束后的空白边界，最终独立脚本 63 项通过；现有老板鼠时间线、首尾回位、减少动态效果和连续点击合并检查通过。最终只读复审未发现必须回修问题。

原生验证以交付证据为准：临时关闭 Codex 来源显示以获得无可见任务的状态，完成后恢复原值；不清除真实任务，不触发权限操作或修改防休眠状态。
