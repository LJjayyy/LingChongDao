# 连接的应用：简洁原生设计

方向：以应用身份、连接状态和操作为核心，采用参考图 2 的明亮原生 macOS 视觉。保留品牌铜色、应用图标与绿色状态；连接页使用中性背景、轻描边和阴影，不改其他页面的配色。

调整：28pt 页面标题、19pt 应用名、48pt 应用图标，22pt 卡片内边距；正常连接删除重复活动说明，版本主行只保留桌面版本。完整检测信息、权限范围与安装说明保留在 ⓘ 原生浮层；错误和待审阅信息继续直接显示。已安装状态只显示重启和开启新会话的指引。打开、安装、手动导出集中排布，窄窗口自适应纵向布局；删除仍沿用确认弹窗。连接页不再展示顶部欢迎区。

动效：保留现有按钮按下反馈、页面淡入及减少动态效果设置；详情使用原生 popover。检查连接时显示进行中文字并防止重复点击。

验证：调试构建与原生离屏截图，内容区宽 600 / 850pt、高 800pt，输出为 2x PNG。一轮独立视觉评审未发现重叠或裁切，指出待验证文字偏长，已精简。预览程序未包含 Codex 插件资源，截图中的资源缺失提示仅反映预览环境；其余连接状态读取本机配置，活动日期由预览程序在内存中设置用于展示。没有安装、卸载或写入来源应用配置。

边界：截图验证不代替真实点击与动效验收，本轮未执行插件安装、导出、删除操作，也未替换已安装应用。截图仅覆盖连接页内容区。
