# 发布安全修复验收

日期：2026-11-02。处理范围为发布产物中的本机路径与本地 Git 快照隐私残留。不提交、不推送、不打标签、不发布，不升级版本，也不替换正在使用的本机应用。

## 构建与发布门禁

- Release 编译加入源码路径、调试路径映射与稳定编译目录，复制后剥离调试记录；helper 在插件哈希生成前重新签名。
- MenuBarIcon、DefaultPetView 两处开发资源 `#filePath` 回退仅在 DEBUG 编译；打包应用仍读取原有 Bundle 素材。
- Info.plist 标记构建类型。新增 `scripts/verify-release-security.py` 递归检查 app 与嵌套插件 ZIP，拒绝 Debug/未知来源、本机 home/checkout 路径、常见凭据、私密文件、危险 ZIP 路径和符号链接。输出不回显敏感匹配值。
- `package-dmg.sh --no-build` 同样必须通过门禁。9 项安全回归已加入 verify-all，Python 缓存列入忽略规则。

首次 Release 验证被新门禁拦截，定位到两处开发资源路径常量后修复；最终 app（含插件目录和 ZIP 内 helper）通过。这不是单纯更改扫描规则或忽略命中。

先前全引用扫描混入了 Codex 的本地 tree checkpoint。逐引用核对后确认：

- main、origin/main、v0.1.40 的公开历史共 284 个 blob，真实用户目录命中为零。
- 全部引用中，19 个含真实路径的旧 blob 仅由 5 个本地 Codex checkpoint 引用保留。
- 完整 `.git` 备份逐文件 SHA-256 校验及 fsck 通过，目录 0700、文件 0600；另有公开历史 bundle。
- 在隔离副本原子删除验证后，以 old OID 校验事务精确移除原仓这 5 个引用，保留其余 8 个干净 Codex 引用。
