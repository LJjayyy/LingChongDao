## 灵宠岛 0.1.45

- 新增「开机自启动」，默认关闭。开启后，登录 Mac 时灵宠岛在后台运行，顶部岛按当前设置显示，工作台保持关闭。开关跟随 macOS 登录项状态，系统要求批准或修改失败时会给出处理入口。
- 工作台侧栏新增「设置」，将「实用工具」中的「开机自启动」和「保持唤醒（含合盖）」集中放在这里。

### 下载与安装

支持 macOS 14 及以上版本和 Apple Silicon（M 系列）Mac。

0.1.43 及以上版本可点击工作台左下角的版本号更新。更早版本请下载 `LingChongDao-0.1.45-macOS-arm64.dmg`，退出灵宠岛后拖入“应用程序”替换并启动。

安装更新需要重启灵宠岛，当前内存任务列表不会恢复，请先处理正在等待的操作。

附件 `SHA256SUMS.txt` 可用于核对安装包和更新清单。应用采用 ad hoc 签名，尚未经过 Apple 公证。首次打开若被 macOS 拦截，请确认下载来源后按 [Apple 官方说明](https://support.apple.com/zh-cn/102445)处理。
