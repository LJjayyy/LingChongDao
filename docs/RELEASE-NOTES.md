## 灵宠岛 0.1.43

- 新增应用内更新：后台静默检查新版本，仅在工作台左下角版本号旁显示红点。
- 点击版本号可查看更新说明，自主选择下载、安装并重启；不会自动弹窗或自动安装。
- 支持稍后更新和跳过版本，网络暂不可用时不打扰工作。
- 更新包采用固定 Ed25519 密钥签名，下载后验证来源与完整性。

### 下载与安装

支持 macOS 14 及以上版本和 Apple Silicon（M 系列）Mac。

首次升级到本版本，请下载 `LingChongDao-0.1.43-macOS-arm64.dmg`，退出旧版灵宠岛后拖入“应用程序”替换并启动。旧版本不含更新器，仍需手动安装这一次；后续版本可在应用内更新。已有连接配置继续保留。

安装更新需要重启灵宠岛，当前内存任务列表不会恢复，请先处理正在等待的操作。

附件 `SHA256SUMS.txt` 可用于核对安装包和更新清单。应用采用 ad hoc 签名，尚未经过 Apple 公证；首次打开若被 macOS 拦截，请确认下载来源后，按 [Apple 官方说明](https://support.apple.com/zh-cn/102445)处理。
