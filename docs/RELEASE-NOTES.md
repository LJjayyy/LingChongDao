## 灵宠岛 0.1.44

- 普通 macOS WorkBuddy 5.9.3 支持逐会话收起结束提醒。在 WorkBuddy 中查看哪条会话，岛上就收起对应提醒。灵宠岛只读查询本机会话状态，每轮结果独立判断。
- 更新随附的 DeepSeek Harness 插件至 0.4.0。在 DSH 中直接打开并查看会话，也能收起岛上对应的结束提醒。更新插件后重启 DSH 生效。
- 两项同步都沿用「回到应用后收起结束提示」开关。

### 下载与安装

支持 macOS 14 及以上版本和 Apple Silicon（M 系列）Mac。

0.1.43 用户可点击工作台左下角的版本号更新。更早版本请下载 `LingChongDao-0.1.44-macOS-arm64.dmg`，退出灵宠岛后拖入“应用程序”替换并启动。

安装更新需要重启灵宠岛，当前内存任务列表不会恢复，请先处理正在等待的操作。

附件 `SHA256SUMS.txt` 可用于核对安装包和更新清单。应用采用 ad hoc 签名，尚未经过 Apple 公证。首次打开若被 macOS 拦截，请确认下载来源后按 [Apple 官方说明](https://support.apple.com/zh-cn/102445)处理。
